# 멈춰버린 학교 : 비례식의 비밀

초등학교 6학년 2학기 「비례식과 비례배분」 학습용 교실 게임 (학생 4~10명 + 선생님)

게임 모드 2가지 — 하나의 게임(같은 맵·캐릭터·수학 미션)에서 규칙만 바뀝니다.
- ❄️ **얼음땡**: 학생 vs 술래. 잡히면 얼음, 친구가 [땡] 하면 다시 움직여요.
- 🕵️ **어몽어스**: 학생 vs 숨어 있는 방해꾼. 얼려진 학생은 유령이 되고, 얼음 흔적을 신고하면 긴급회의·투표.

## 2. 바로 실행해 보기 (Firebase 없이)

1. 폴더 안의 `index.html` 을 **Chrome 또는 Edge** 로 엽니다. (더블클릭)
2. 메인 화면 아래에 「🖥 이 컴퓨터 안 모드」라고 나오면 정상입니다.
3. **같은 브라우저에서 탭을 여러 개** 열면 여러 명이 들어온 것처럼 테스트할 수 있어요.
   - 탭1 (선생님): [🧑‍🏫 교사용] → 교사 PIN(처음 값 `1234`) → 게임 모드·설정 고르기 → [방 만들기] → 방 번호 확인
   - 탭2, 탭3… (학생): 닉네임 + 방 번호 → [방 참가하기]
   - 선생님 화면에서 [게임 시작]
4. 혼자 테스트할 때는 선생님 대기방의 **🐞 DEBUG → [봇 추가]** 를 누르세요. 봇이 학교를 돌아다닙니다.
   (DEBUG 모드에서는 학생 1명이어도 시작할 수 있어요. 얼음땡에서 술래 봇은 학생을 잡고, 학생 봇은 친구를 땡 해 줘요.)
5. 게임 중 왼쪽 가운데의 **🐞** 버튼을 누르면 테스트 도구가 열립니다.
   - 내 역할 강제(학생 탭에서 게임 시작 전에 「술래 / 방해꾼」 고르기) · 모든 미션 위치 보기 · 내 미션 1개 즉시 완료
   - 미션 화면의 **🐞 정답 넣기** 버튼으로 정답을 자동으로 넣어 볼 수 있어요.

### 문제를 고치거나 추가하려면
`js/questions.js` 만 고치면 됩니다. 문제마다
`question`(전체 문장), `lines`(미션 화면에 보일 짧은 2~3줄), `answer`, `hint`, `steps`, `explanation` 이 있어요.
같은 `missionType` 의 문제를 복사해서 숫자만 바꾸면 그 장소 미니게임에 자동으로 나옵니다.

> 이 모드는 **같은 컴퓨터·같은 브라우저 안에서만** 함께 놀 수 있습니다.
> 여러 태블릿으로 함께 하려면 아래 3번의 Firebase 연결이 필요해요.

## 3. 여러 태블릿으로 함께 하기 (Firebase 연결)

1. [Firebase 콘솔](https://console.firebase.google.com) → 프로젝트 선택(기존 프로젝트도 괜찮아요)
2. 왼쪽 메뉴 **빌드 → Realtime Database** → 데이터베이스 만들기
3. **규칙** 탭에 아래 내용을 넣고 [게시] (이미 다른 게임 규칙이 있으면 `"ratioSchool"` 부분만 추가)

   ```json
   {
     "rules": {
       "ratioSchool": { ".read": true, ".write": true }
     }
   }
   ```

4. **프로젝트 설정(톱니바퀴) → 내 앱 → 웹 앱** 의 `firebaseConfig` 값을
   `js/firebase-config.js` 에 그대로 붙여넣습니다. **databaseURL 이 꼭 있어야 해요.**
5. 다시 열었을 때 메인 화면에 「🌐 온라인 모드」가 나오면 연결 성공입니다.

게임 데이터는 데이터베이스의 `ratioSchool/` 아래에만 저장되어 다른 게임 데이터와 섞이지 않습니다.

## 5. 수업 전에 꼭 바꿀 것

`js/config.js` 맨 위의 두 줄입니다.

```js
const DEBUG_MODE = true;       // → false 로 (🐞 버튼, 봇, 1명 시작 기능이 사라지고 학생 4명 이상이어야 시작돼요)
const TEACHER_PIN = "1234";    // → 선생님만 아는 숫자로
```

> 교사 PIN 은 **이 한 곳에서만** 관리합니다.
> GitHub Pages 에 올린 파일은 누구나 열어 볼 수 있으므로, PIN 은 강한 보안이 아니라
> **학생이 실수로 방을 만들지 않게 하는 수업용 잠금**입니다.

## 5-1. 선생님이 하는 일 (수업 흐름)

1. [🧑‍🏫 교사용] → PIN → **게임 모드**(❄️ 얼음땡 / 🕵️ 어몽어스)와 시간·미션 수·난이도·모드별 설정 → [방 만들기]
2. 칠판에 방 번호를 적어 주세요. 학생은 **닉네임 + 방 번호**만 넣으면 들어와요. (학생에게는 방 만들기·PIN 이 보이지 않아요)
   - 대기방 위쪽의 **[🔗 초대 링크 복사]** 로 `게임주소/?room=방번호` 링크를 복사해 학급 채팅에 올리거나,
     **[▦ QR 코드 보기]** 로 큰 QR 을 띄워 태블릿 카메라로 찍게 하면 방 번호가 자동으로 입력돼요.
   - QR 은 인터넷 서비스 없이 게임 안에서 만들어요. (이 컴퓨터 안 모드·`file://` 로 열었을 때의 QR 은 그 컴퓨터에서만 열리므로, 학생 태블릿용 QR 은 GitHub Pages 주소로 연 화면에서 보여 주세요)
3. 대기방 (선생님 화면에만 보이는 버튼)
   - **[게임 시작]** · **[⚙ 게임 설정]** (모드·설정 바꾸기) · **[👥 플레이어 관리]** (학생 내보내기) · **[📊 지난 게임 학습 결과]** · **[방 닫기]**
   - 어몽어스에서는 대기방 오른쪽 **🕵️ 방해꾼 설정** 칸(선생님 화면에만 보임)에서 **[자동] / [직접 선택]** 과 방해꾼 수를 고르세요.
     직접 선택은 학생 이름을 눌러 ☑ 하고, 고른 수가 방해꾼 수와 정확히 같아야 시작돼요. 고른 명단은 선생님 기기에만 있고 학생 기기로는 전달되지 않아요.
   - 방 번호 옆 **[📋 방 코드 복사] [🔗 초대 링크 복사] [▦ QR 코드 보기]**
   - 캐릭터 색은 학생이 고르지 않고 자동으로 정해져요. 같은 방에서는 색이 겹치지 않아요.
4. 선생님은 캐릭터 없이 **진행자**로 참여해요. 게임 중 선생님 화면:
   - 학교 전체 지도 · 남은 시간 · 학교 복구율 · 학생 상태(정상/얼음/보호/유령/나감)
   - **[👁 위치 보기]**, **[🎭 역할 보기]** 는 누를 때만 보여요. (TV 에 띄울 때 정체가 드러나지 않도록)
   - **[⏹ 게임 강제 종료]** (두 번 눌러야 실행)
5. 게임이 끝나면 선생님 화면에 **전체 학습 결과**가 바로 열려요. (CSV 내려받기 · [대기방으로 (다시 하기)])
6. 선생님 탭이 잠깐 닫히거나 **뒤로 숨겨져도** 게임은 계속돼요. (가장 먼저 들어온 학생 화면이 대신 심판을 맡고, 선생님 화면이 다시 보이면 다시 선생님이 맡아요)
   브라우저는 숨겨진 탭의 시계를 크게 늦추기 때문에, 예전에는 한 컴퓨터에서 탭 여러 개로 테스트할 때 신고·게임 종료가 늦어질 수 있었어요.

## 5-2. 두 게임 모드 규칙

| | ❄️ 얼음땡 | 🕵️ 어몽어스 |
|---|---|---|
| 역할 | 학생 / 술래 (술래는 머리 위 「술래」 표시로 공개) | 학생 / 방해꾼 (겉모습으로 구별 불가 · 자기 화면에서만 역할 확인) |
| 학생 할 일 | 수학 미션으로 학교 복구 | 수학 미션으로 학교 복구 · 방해꾼 찾기 |
| 특별 역할 | 술래 [잡기] → 학생이 얼음 (쿨타임 기본 7초) | 방해꾼 [얼리기] → 학생 탈락·유령 (쿨타임 기본 25초) + [방해] 정전·문 잠금·위장 |
| 얼었을 때 | 움직이기·미션 불가 → 친구가 옆에서 [땡] 약 1초 → 풀림 + 약 5초 보호 | 땡 불가 · 유령이 되어 벽 통과 · 미션 계속 가능(복구율 오름) · 회의·투표·신고 불가 · 그 자리에 얼음 흔적 |
| 회의 | 없음 | 얼음 흔적 [신고](학생·방해꾼 모두 가능, 유령 불가) 또는 긴급회의 버튼(일반 학생만) → 토론 25초 → 투표 15초 (자기 자신 X · 건너뛰기) · 회의·투표 화면에는 닉네임 없이 캐릭터 색만 |
| 학생팀 승리 | 학교 복구율 100% | 학교 복구율 100% 또는 방해꾼 모두 투표로 찾기 |
| 상대팀 승리 | 모든 학생이 동시에 얼음 · 시간 종료 | 살아 있는 학생 수 ≤ 살아 있는 방해꾼 수 (1대1 · 2대2 즉시) · 시간 종료 |

- 게임 중에는 캐릭터 위에 **닉네임이 보이지 않아요.** 색과 행동으로 구별해요. (닉네임은 대기방·회의·투표·결과 화면에만)
- 얼음땡에서 얼어 있는 동안에는 미션 제한 시간도 멈춰요.
- 두 모드 모두 수학 미션 · 문제은행 · 학교 복구율 · 나의 수학 기록 · 교사용 결과가 그대로 쓰여요.

## 6. 수업 중에 알아 두면 좋은 것

- **새 파일을 올렸는데 바뀐 기능이 안 보이면**: 메인 화면 아래의 「버전 5-2」를 확인하세요. 예전 버전이 보이면 GitHub 저장소에 파일이 다 올라갔는지 확인하고, 1~2분 뒤 Ctrl+Shift+R(태블릿은 새로고침)을 해 주세요.

- **게임이 끝나면** 약 3초 뒤 학생마다 「나의 수학 기록」이 나옵니다.
  선생님 화면에는 **전체 학습 결과**가 바로 열리고, 여기서 **CSV(엑셀)** 로 내려받을 수 있어요.
  대기방으로 돌아간 뒤에도 다음 게임을 시작하기 전까지는 **📊 지난 게임 학습 결과** 버튼으로 다시 볼 수 있어요.
- 학생이 게임 중 **⚙ → [대기방으로 나가기]** 를 누르면 (확인창을 한 번 더 보여 줘요) 그 판에서만 빠지고
  「다음 게임을 기다리는 중」 화면이 나와요. 선생님이 다음 게임을 시작하면 자동으로 참가해요.
- **⚙ 환경설정**: 전체 · 배경음악 · 효과음 음량(0~100, 기기마다 저장), 배경음악·효과음 켜기/끄기, 조작 방법, 전체화면.
  배경음악은 미션(수학 문제)을 푸는 동안 저절로 작아져요.
- **태블릿 화면이 꺼지거나 새로고침해도** 60초 안에 돌아오면 그대로 이어서 할 수 있어요.
  - 같은 탭이면 자동으로 다시 들어가요.
  - 탭을 닫았다면 게임 주소를 다시 열고 **🔄 게임으로 돌아가기** 버튼을 누르세요.
  - 60초가 지나도 돌아오지 않으면 그 학생의 미션은 학교 복구율 계산에서 빠져요. (나중에 돌아오면 다시 들어가요)

## 7. 조작 방법

| | 컴퓨터 | 태블릿 |
|---|---|---|
| 이동 | WASD / 방향키 | 화면 왼쪽을 누르고 끌기 (조이스틱) |
| 미션 풀기 | 반짝이는 내 장치 앞에서 E | 장치 앞에서 [미션] 버튼 (노랗게 반짝일 때) |
| 미션 안에서 | 숫자키 · Enter(확인) · Esc(나가기) | 화면 버튼·슬라이더·끌어다 놓기 |
| ❄️ 땡 (학생) | 얼어 있는 친구 옆에서 R 을 누르고 있기 | [땡] 버튼을 누르고 있기 |
| ❄️ 잡기 (술래) | 학생 옆에서 Q 또는 스페이스 | [잡기] 버튼 |
| 🕵️ 신고 / 긴급회의 | 얼음 흔적 옆 또는 중앙 복도 빨간 버튼 앞에서 R | 빨갛게 빛나는 [신고]/[긴급회의] 버튼 |
| 🕵️ 얼리기 (방해꾼) | 학생 옆에서 Q 또는 스페이스 | [얼리기] 버튼 (남은 시간 표시) |
| 🕵️ 방해 (방해꾼) | F (열기) · 1 정전 · 2 문 잠금 · 3 위장 | [방해] → 보라색 버튼 3개 |
| 지도 | M | [지도] 버튼 |
| 환경설정 | ESC | 오른쪽 위 ⚙ |
| 전체 화면 | 오른쪽 위 ⛶ | 오른쪽 위 ⛶ |

태블릿은 **가로 방향**으로 사용합니다. (세로로 들면 안내가 나와요.)
