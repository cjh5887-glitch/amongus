# 멈춰버린 학교 : 비례식의 비밀

초등학교 6학년 2학기 「비례식과 비례배분」 학습용 추리 게임 (4~10명)

---

## 1. 폴더 구조와 파일 역할

```
index.html              모든 화면의 틀 (메인·대기실·역할·스토리·게임·종료)
css/
  style.css             공통 디자인 (어두운 학교 + 네온 UI, 태블릿 대응)
  mission.css           미션 공통 화면 · 미니게임 8개 · 학교 지도
  meeting.css           긴급회의·투표 화면 · 방해꾼 능력 버튼 · 정전/얼음/유령 알림
  result.css            게임 종료 연출 · 나의 수학 기록 · 교사용 결과 표
js/
  config.js             ★ 설정값 모음 (시간·속도·쿨타임·DEBUG_MODE)
  firebase-config.js    ★ Firebase 프로젝트 정보를 붙여넣는 곳
  utils.js              여러 파일이 함께 쓰는 작은 함수
  questions.js          ★ 문제은행 60문제 (선생님이 문제를 고칠 때는 이 파일만)
  sound.js              효과음 (파일이 없어도 오류 없음)
  state.js              GameStateManager — 게임 상태를 한 곳에서만 바꿈
  network.js            방 만들기·참가·실시간 동기화 (Firebase / 이 컴퓨터 안)
  input.js              키보드(WASD·방향키) + 태블릿 조이스틱
  map.js                학교 맵 데이터 · 충돌 판정 · 맵 그리기
  player.js             캐릭터 그리기 · 이동 · 다른 플레이어 위치 보간
  roles.js              역할 배정 (학생 / 방해꾼)
  renderer.js           카메라 · 시야(어둠) · 화면 그리기
  ui.js                 화면·HUD·설정 창 표시
  debug.js              개발용 테스트 도구 (🐞 버튼)
  game.js               게임 전체 흐름 (시작점, 방장 심판 기능)
  mission.js            개인 미션 배정 · 미션 장치 · 학교 복구율 · 가짜 미션 · 학습 기록
  minigames.js          공통 미션 화면 + 장소별 미니게임 8개 (정답 판정은 여기 한 곳)
  abilities.js          방해꾼 능력 4개 (정전 · 문 잠금 · 위장 · 얼리기) + 플레이어 상태
  meeting.js            긴급회의 · 신고 · 투표 · 유령 · 투표 관련 승패
  analytics.js          나의 수학 기록 · 교사용 전체 학습 결과 · CSV 다운로드
assets/
  images/               (선택) map.png 를 넣으면 맵 배경으로 사용
  sounds/               (선택) start.mp3, correct.mp3 … 를 넣으면 효과음 재생
```

★ 표시 파일이 선생님이 직접 고칠 일이 있는 파일입니다.

## 2. 바로 실행해 보기 (Firebase 없이)

1. 폴더 안의 `index.html` 을 **Chrome 또는 Edge** 로 엽니다. (더블클릭)
2. 메인 화면 아래에 「🖥 이 컴퓨터 안 모드」라고 나오면 정상입니다.
3. **같은 브라우저에서 탭을 여러 개** 열면 여러 명이 들어온 것처럼 테스트할 수 있어요.
   - 탭1: 닉네임 → [방 만들기] → 방 번호 확인
   - 탭2, 탭3…: 다른 닉네임 → 방 번호 입력 → [방 참가하기]
4. 혼자 테스트할 때는 대기실의 **🐞 DEBUG → [봇 추가]** 를 누르세요. 봇이 학교를 돌아다닙니다.
   (DEBUG 모드에서는 1명이어도 시작할 수 있어요.)
5. 게임 중 왼쪽 가운데의 **🐞** 버튼을 누르면 테스트 도구가 열립니다.
   - 내 역할 강제(방장일 때, 게임 시작 전에 고르기) · 모든 미션 위치 보기 · 내 미션 1개 즉시 완료
   - 미션 화면의 **🐞 정답 넣기** 버튼으로 정답을 자동으로 넣어 볼 수 있어요.

### 문제를 고치거나 추가하려면
`js/questions.js` 만 고치면 됩니다. 문제마다
`question`(전체 문장), `lines`(미션 화면에 보일 짧은 2~3줄), `answer`, `hint`, `steps`, `explanation` 이 있어요.
같은 `missionType` 의 문제를 복사해서 숫자만 바꾸면 그 장소 미니게임에 자동으로 나옵니다.

> 이 모드는 **같은 컴퓨터·같은 브라우저 안에서만** 함께 놀 수 있습니다.
> 여러 태블릿으로 함께 하려면 아래 3번의 Firebase 연결이 필요해요.

## 3. 여러 태블릿으로 함께 하기 (Firebase 연결)

1. [Firebase 콘솔](https://console.firebase.google.com) → 프로젝트 선택(기존 프로젝트도 괜찮아요)
2. 왼쪽 메뉴 **빌드 → Realtime Database** → 데이터베이스 만들기
3. **규칙** 탭에 아래 내용을 넣고 [게시] (이미 다른 게임 규칙이 있으면 `"ratioSchool"` 부분만 추가)

   ```json
   {
     "rules": {
       "ratioSchool": { ".read": true, ".write": true }
     }
   }
   ```

4. **프로젝트 설정(톱니바퀴) → 내 앱 → 웹 앱** 의 `firebaseConfig` 값을
   `js/firebase-config.js` 에 그대로 붙여넣습니다. **databaseURL 이 꼭 있어야 해요.**
5. 다시 열었을 때 메인 화면에 「🌐 온라인 모드」가 나오면 연결 성공입니다.

게임 데이터는 데이터베이스의 `ratioSchool/` 아래에만 저장되어 다른 게임 데이터와 섞이지 않습니다.

## 4. GitHub Pages 에 올리기

1. GitHub 에서 새 저장소를 만들고, 이 폴더의 **모든 파일과 폴더**를 그대로 올립니다.
   (`index.html` 이 저장소 맨 위에 있어야 해요.)
2. 저장소 **Settings → Pages → Branch: main / (root)** → Save
3. 1~2분 뒤 나오는 주소를 학생들에게 알려 주세요.

## 5. 수업 전에 꼭 바꿀 것

`js/config.js` 맨 위의

```js
const DEBUG_MODE = true;
```

를 **`false`** 로 바꾸세요. (🐞 버튼, 봇, 1명 시작 기능이 사라지고 4명 이상이어야 시작돼요.)

## 6. 수업 중에 알아 두면 좋은 것

- **게임이 끝나면** 약 3초 뒤 학생마다 「나의 수학 기록」이 나옵니다.
  방장(선생님) 화면에는 **🧑‍🏫 전체 학습 결과** 버튼이 있고, 여기서 **CSV(엑셀)** 로 내려받을 수 있어요.
  대기실로 돌아간 뒤에도 다음 게임을 시작하기 전까지는 **📊 지난 게임 학습 결과** 버튼으로 다시 볼 수 있어요.
- **태블릿 화면이 꺼지거나 새로고침해도** 60초 안에 돌아오면 그대로 이어서 할 수 있어요.
  - 같은 탭이면 자동으로 다시 들어가요.
  - 탭을 닫았다면 게임 주소를 다시 열고 **🔄 게임으로 돌아가기** 버튼을 누르세요.
  - 60초가 지나도 돌아오지 않으면 그 학생의 미션은 학교 복구율 계산에서 빠져요. (나중에 돌아오면 다시 들어가요)

## 7. 조작 방법

| | 컴퓨터 | 태블릿 |
|---|---|---|
| 이동 | WASD / 방향키 | 화면 왼쪽을 누르고 끌기 (조이스틱) |
| 미션 풀기 | 반짝이는 내 장치 앞에서 E | 장치 앞에서 [미션] 버튼 (노랗게 반짝일 때) |
| 미션 안에서 | 숫자키 · Enter(확인) · Esc(나가기) | 화면 버튼·슬라이더·끌어다 놓기 |
| 긴급회의 / 신고 | 중앙 복도 빨간 버튼 앞 또는 얼어 있는 친구 옆에서 R | 빨갛게 빛나는 [긴급회의]/[신고] 버튼 |
| 방해꾼 능력 | 1 정전 · 2 문 잠금 · 3 위장 · 4 얼리기 | 보라색 능력 버튼 4개 (방해꾼에게만 보임) |
| 미션 · 신고 · 지도 · 능력 | E · R · M · 1~4 | 오른쪽 아래 버튼 |
| 전체 화면 | 오른쪽 위 ⛶ | 오른쪽 위 ⛶ |

태블릿은 **가로 방향**으로 사용합니다. (세로로 들면 안내가 나와요.)
