확인이 필요한 곳

순서

  1. console.firebase.google.com 에서 프로젝트 만들기
  2. Realtime Database → 데이터베이스 만들기 → 테스트 모드
  3. 그 다음에 프로젝트 설정 → 내 앱 → 웹 앱 추가 → firebaseConfig 복사
  4. 이 파일에 붙여넣고 저장 (databaseURL 줄이 꼭 있어야 해요)
자주 겪는 문제

databaseURL 줄이 없다 — Realtime Database를 만들기 전에 config를 복사하면 이 줄이 안 나옵니다. 데이터베이스를 먼저 만들고 config를 다시 복사하세요.

깃허브에 옛날 파일이 올라가 있다 — 내 컴퓨터에서 고친 파일이 아니라 예전 파일을 올린 경우입니다. 깃허브에서 index.html을 눌러 apiKey 줄이 실제 값인지 직접 확인해 보세요.

브라우저가 옛 화면을 기억하고 있다 — 주소 뒤에 ?v=2 를 붙여서 다시 열어 보세요.
